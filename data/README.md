# Данные

В проекте используется **AG News Classification Dataset**.

Исходные файлы данных не включены в репозиторий:

```text
train.csv
test.csv
```

В исходной курсовой использовались 120 000 train-объектов и 7 600 test-объектов, которые были объединены и затем повторно разделены для эксперимента.
